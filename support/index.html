WebHarbor 4.0

Build 29 includes separate workspaces, JZ and Trip webpage entries, an inbox, Share saving, three Shortcuts actions, local reminders, configured Native sources and nine interface languages. JZ opens its ordinary website; the native bookkeeping integration remains excluded. Built-in Port, location reminders and sampling are not offered in 4.0. Earlier-version instructions below remain for existing users and do not enable those features in 4.0. Native history/status queries cover 30 days and deduplication lookups cover 90 days; these are not physical-deletion guarantees. See the privacy policy for current retention.

Free workspaces and cloud notification allowance

New installations start with JZ and Trip using two of three free workspace slots. Permanent Unlock is a non-consumable, one-time purchase with a US base price of $4.99; the actual local price is shown by Apple. There is no subscription or separate per-notification purchase. Existing workspace lists are preserved.

Enrolled authenticated installation identities receive 50 cloud notifications in total. The count is shared across participating notification routes for that installation. A unique accepted message is counted once; retries, duplicate delivery, history retrieval and local reminders do not consume another allowance. After the free allowance is exhausted, the service explicitly rejects additional new cloud messages rather than claiming they were accepted. Permanent Unlock is a one-time purchase that removes this commercial message limit; technical anti-abuse limits still apply. Apple displays the actual local purchase price. This is an installation-identity limit, not an unresettable lifetime limit per person or Apple Account; a new installation identity may receive a new allowance. Previously unenrolled installations are not silently migrated.

Earlier versions: 3.0 cloud inbox and private push entries

When enabled for your build, open a workspace's Notifications page. Developers choose Create push entry and copy a ready-to-run request to their server or script. No topic or device ID is required. GitHub users choose Connect GitHub, authorize the official App, select repositories and confirm the verified account. Website sign-in is separate. Repository permissions or organization approval may limit access. Slack and full Bark/ntfy protocol compatibility are not included.

The bell opens all messages; entering from a workspace filters that workspace. Messages are available for 30 days even if iOS banners are disabled. Refresh after reconnecting to the network. Test phone notification checks only the gateway-to-phone path; the source is verified only when its first real request arrives. APNs acceptance is not a phone receipt. If authorization expires, reconnect; if iOS alerts are disabled, use iPhone Settings. Changing the app language updates generated notices, not message text supplied by users. Credentials are device-bound: no account, reinstall or cross-device notification restoration is promised.

Earlier versions: Optional workspace notifications (3.0)

When the service is available, open your signed-in supported website and choose Enable WebHarbor Notifications. Confirm in the app and allow iOS notifications. For a Hezhang workspace, alerts can show the actor, amount and category when lock-screen details are enabled; turn on Hide lock-screen details to keep the alert generic. For GitHub, first add a github.com workspace, then use Settings → Notifications and official authorization. Notification permission does not connect arbitrary websites automatically.

Use Settings → Notifications to disconnect, hide lock-screen details or clear local history. Clearing website data can either keep or turn off notifications; deleting a workspace always turns them off locally and queues server revocation. Delivery and local history are best effort, not guaranteed. Check iPhone notification permissions and Focus settings if reminders do not appear.

Restore Permanent Unlock

Open Settings, choose Permanent Unlock, then tap Restore Purchases with the same Apple Account used to buy it. The purchase restores supported paid features and, after online service verification, removes the commercial cloud message cap for an enrolled installation. Pending or unavailable verification is shown rather than treated as confirmed. Purchase restoration does not sync website cookies, login data or inbox history between devices. Do not send us your Apple password or a purchase private key.

Clear a website login

Long-press a workspace, choose Clear Website Data, and confirm. The workspace name, URL and icon stay in place while cookies, LocalStorage, IndexedDB and cache are removed.

Uploads and downloads

Web pages use the iOS file picker for uploads. A supported download is staged temporarily and can be exported with Save to Files. Closing a runner while a download is active asks for confirmation; no background resume is promised.

OAuth and SSO

Some providers, including Google and enterprise SSO services, refuse embedded WebViews or require an external browser callback. WebHarbor does not spoof Safari, inject scripts or bypass TLS. Use Open in Safari when the website provides that option.

Need help?

Include the app version, iOS version and a description of the page or action. Never send passwords, cookies or access tokens.

WebHarbor 4.0

29 构建包含独立工作区、JZ 与 Trip 网页入口、收件箱、分享保存、三项快捷指令、本地提醒、已配置的 Native 来源和九种界面语言。JZ 只打开普通网站，不恢复原生记账集成；4.0 不提供内建 Port、位置提醒或采样；下方旧版指引为既有用户保留，不代表在 4.0 启用这些功能。Native 的 30 天历史/状态查询和 90 天去重查询窗口不是物理删除保证，当前保留边界请见隐私政策。

免费工作区与云通知额度

新安装预置JZ与Trip，占用三个免费工作区名额中的两个。永久解锁为非消耗型一次性购买，美国基准价为US$4.99，实际当地价格以Apple购买页面为准；没有订阅或按条单独购买通知。升级保留既有工作区列表。

已加入该规则的已认证安装身份累计可接收 50 条云通知，同一安装在适用通知链路间共享额度。每条唯一且成功接收的消息只计一次，重试、重复投递、历史补拉和本地提醒不会再扣额度。免费额度用尽后，服务明确拒绝新的云消息，不会声称已接收。永久解锁为一次性购买，可取消这一商业数量限制，正常防滥用技术限流仍保留，实际当地价格以 Apple 购买页面为准。这是按安装身份计算，不是按个人或 Apple 账户永久不可重置；新安装身份可能取得新额度。原本未加入规则的旧安装不会被静默纳入。

早期版本：3.0 云端收件箱与私有推送入口

当前构建开放后，进入工作区的“通知”页面。开发者选择“创建推送入口”，将完整请求复制到服务器或脚本，无需填写 Topic 或设备 ID。GitHub 用户选择“连接 GitHub”，通过官方 App 授权、选择仓库并确认账号；网页登录相互独立，组织审批和仓库权限可能限制接收范围。不包含 Slack 或完整 Bark/ntfy 协议兼容。

首页铃铛查看全部消息，从工作区进入则筛选当前工作区。即使关闭 iOS 横幅，也可以查看最近 30 天消息，网络恢复后下拉刷新。“测试手机提醒”只验证网关到手机这一段，来源实际发送第一条请求后才算验证接入。APNs 接受不等于手机收到。授权过期需重新连接，手机提醒未开启需到 iPhone 设置打开。App 语言切换更新系统生成文案，不翻译用户发送的原文。凭据仅绑定当前设备，不承诺账户、重装或跨设备通知恢复。

早期版本：3.0 可选工作区通知

服务可用后，在支持的网站登录并点击“开启 WebHarbor 提醒”，在 App 中确认并允许 iOS 通知。合账工作区在允许锁屏详情时会显示记账人、金额和分类；打开“隐藏锁屏详情”后只显示通用提醒。GitHub 需先添加 github.com 工作区，再进入“设置 → 通知”通过官方授权。授予系统权限不会自动连接任意网站。

可在“设置 → 通知”关闭提醒、隐藏锁屏详情或清除本机历史。清除网页数据可选择保留或关闭提醒；删除工作区始终立即停用本地提醒并排队撤销服务器订阅。通知投递及本机记录均为尽力提供，不保证完整。收不到提醒时，请检查 iPhone 通知权限和专注模式。

恢复永久解锁

打开“设置”，选择“永久解锁”，使用购买时的同一 Apple 账户点按“恢复购买”。购买恢复支持的付费功能；已加入规则的安装经在线服务核验后可取消云通知商业数量上限。核验待定或不可用会显示状态，不冒充已经确认。恢复购买不会在设备之间同步网站 Cookie、登录数据或收件箱历史。请勿发送 Apple 密码或购买验证私钥。

清除网站登录

长按工作区，选择“清除网站数据”并确认。工作区名称、网址和图标会保留，但 Cookie、LocalStorage、IndexedDB 和缓存会被删除。

上传和下载

网页上传使用 iOS 系统文件选择器。支持的下载会暂存在临时目录，可通过“保存到文件”导出。下载期间关闭工作区会请求确认；不会承诺后台续传。

OAuth 和 SSO

部分服务（包括 Google 及企业 SSO）会拒绝嵌入式 WebView，或要求外部浏览器回调。WebHarbor 不伪造 Safari、不注入脚本，也不绕过 TLS。网页提供选项时，请使用“在 Safari 中打开”。
